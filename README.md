This entry presents 19 November's world news in one static image. The Node 22 program validates the bundled image's format, size, and dimensions, then copies it byte for byte to the output directory without network access or dependencies.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
